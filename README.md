# jogo-da-velha
Jogo da Velha em Python
Projeto de Jogo da Velha desenvolvido em Python como parte dos meus estudos em programação.

## Sobre o Projeto
O jogo permite duas formas de partida:
- 👤 Jogador contra computador
- 👥 Jogador contra jogador
O computador realiza suas jogadas automaticamente e o jogo verifica as condições de vitória e empate.

## Tecnologias Utilizadas
- Python
- Biblioteca 'random'

## Conceitos praticados
Neste projeto pratiquei:
- Variáveis
- Listas
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`while`)
- Entrada de dados com `input()`
- Saída de dados com `print()`
- Uso de biblioteca (`random`)
- Lógica de programação

## Como executar o Código?
-É necessário ter o Python instalado.
-Execute o arquivo: "python jogodavelha.py"
